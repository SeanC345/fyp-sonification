\# Final Year Project - Sonification for Football Training



This repository contains the research, documentation and development work for my Final Year Project at SETU Waterford.



The project is currently investigating how sonification could be used in football training. The main areas being explored are wearable devices that collect player movement data and technology that could collect data from a football.



The exact project scope is still being investigated.



\## Current Work



\- Research into sonification

\- Research into existing ball technologies

\- Wearable device use cases

\- Ball-based use cases

\- Investigation of possible project directions
